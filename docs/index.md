# Classes Framework

C++-style object-oriented programming for Roblox Luau.

A professional Wally package for developers who want scalable architecture with classes, constructors, inheritance, services, and component systems inspired by C++ and modern game engines.

---

## Features

- Class creation
- Constructors
- Inheritance
- Static methods
- Service architecture
- Component systems
- Wally support
- Rojo workflow
- Professional package structure

---

[dependencies]
